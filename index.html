ANOVA + Tukey + LSD Fisher

Pegá tu tabla, definí el alcance del análisis y descargá un Excel trazable. Ahora podés analizar por localidad, por protocolo o ambas opciones en el mismo archivo.

01

Pegar datos

Acepta TSV copiado desde Excel o CSV simple. La primera fila debe contener encabezados.

02

Configurar columnas

Elegí valor, tratamiento, alpha y los cortes del experimento.

Ej: assessment_value

Ej: treatment

Ej: location, localidad, site

Default: 0.05

Elegí las columnas que cortan el experimento. Si existe se_name_mod, se marca automáticamente. La localidad se maneja desde el bloque siguiente para evitar errores.

03

Alcance por localidad

Definí si el modelo separa localidades, junta todas las localidades o descarga ambas lecturas.

Si elegís Ambas, el Excel agrega analysis_scope, analysis_basis y location_analysis_note para distinguir qué líneas pertenecen al análisis por localidad y cuáles al análisis por protocolo.

04

Configuración por se_name_mod

Cuando existe se_name_mod, podés excluir testigos del cálculo sin sacarlos del Excel.

Para cada variable detectada, definí si el testigo entra o no en el análisis. Si no entra, indicá cuál es el treatment testigo. Para Fitotoxicidad (%) y Eficacia (%), el default es excluir testigo.

Todavía no se detectó se_name_mod. Cargá la tabla para revisar esta sección.
